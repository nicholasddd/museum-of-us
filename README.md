# Museum of Us

Build your own miniature museum: hang frames on the wall, add your photos, pick the wallpaper,
floor, lighting and little figurines, and see it as a painted 3D diorama.

## Run it locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

This builds the site and pushes it to the `gh-pages` branch, which GitHub Pages serves at
https://nicholasddd.github.io/museum-of-us/
