# Museum of Us

Build your own miniature museum: hang frames on the wall, add your photos, pick the wallpaper,
floor, lighting and little figurines, and see it as a painted 3D diorama.

## Run it locally

```bash
npm install
npm run dev
```

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages
(see `.github/workflows/deploy.yml`): https://nicholasddd.github.io/museum-of-us/
